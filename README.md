# java-lotto-precourse

1. 구입 금액 입력

 사용자로부터 구입 금액을 입력받는다.

 입력값이 1,000원 단위인지 검증한다.

 잘못된 값 입력 시 에러 메시지 출력 후 재입력 받기.

2. 로또 발행

 구입 금액에 따라 로또 개수를 계산한다.

 중복 없는 6개의 번호 생성.

 생성된 번호를 오름차순 정렬하여 저장한다.

 구매한 모든 로또 번호를 출력한다.

3. 당첨 번호 및 보너스 번호 입력

 당첨 번호 6개를 입력받는다.

 보너스 번호 1개를 입력받는다.

 번호가 1~45 범위에 있는지, 중복되지 않는지 검증한다.

 잘못된 입력 시 에러 메시지 출력 후 재입력 받기.

4. 당첨 결과 계산

 각 로또별로 당첨 번호와 일치하는 개수를 계산한다.

 5개 일치 시 보너스 번호 일치 여부도 판별한다.

 등수에 따른 상금을 계산한다.

 당첨 결과를 출력한다.

5. 수익률 계산 및 출력

 총 상금 합계를 계산한다.

 구입 금액 대비 수익률을 계산한다.

 소수점 둘째 자리에서 반올림하여 출력한다.

 결과 출력 형식에 맞게 정리한다.

6. 예외 처리

 잘못된 입력 시 IllegalArgumentException 발생.

 에러 메시지 출력 후 다시 입력 받기.

 예외는 IllegalArgumentException, IllegalStateException 등 명확한 유형만 사용.

7. 테스트 코드

 로또 번호 생성, 당첨 계산, 수익률 계산 등의 비즈니스 로직을 JUnit5로 단위 테스트한다.

 System.out, System.in 관련 부분은 테스트에서 제외한다.
